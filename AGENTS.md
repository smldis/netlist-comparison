# Netlist Comparison agent guidance

When checked out inside ASS, follow `../AGENTS.md`. For standalone checkouts,
read the local ontology, README and manifest before work; parent files are optional.
This unit owns comparison over public canonical objects, not parsing or circuit
function recognition. Keep raw input, candidate evidence, conditional differences
and unresolved scope distinguishable. Never promote a selected assignment to a
verified identity. Names are labels; repeated feature classes are not proven
automorphisms. Changes to the canonical/comparison contract belong in the parent
ontology. Test edits, ambiguity and budget exhaustion, not only identical inputs.
