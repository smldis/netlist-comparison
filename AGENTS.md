# Netlist Comparison agent guidance

Follow `../AGENTS.md`. Read the local ontology, README and manifest before work.
This unit owns comparison over public canonical objects, not parsing or circuit
function recognition. Keep raw input, candidate evidence, conditional differences
and unresolved scope distinguishable. Never promote a selected assignment to a
verified identity. Names are labels; repeated feature classes are not proven
automorphisms. Changes to the canonical/comparison contract belong in the parent
ontology. Test edits, ambiguity and budget exhaustion, not only identical inputs.

## Version control

This component has its own Git repository (user decision, 2026-09-16). Use focused
local commits for reviewed comparator development, with relevant tests and docs.
Inspect status first and preserve other work. Stage explicit paths; do not commit
parent ASS changes, canonical-parser changes or observatory run artifacts here.
Keep experimental work on topic branches. A local commit does not authorize a
remote publication; no remote is configured at the initial baseline.
